# 景去 · 武汉景色与公交推荐

照片下方提供可编辑的找景提示词：可从照片识别结果生成并复制，也可直接输入景观描述。“按提示词找地点”调用现有智谱模型提取景观标签及具体检索词，再向高德实时搜索武汉候选地并查询公交；提示词解析失败时显示错误，不将默认候选地冒充提示词搜索结果。

上传照片或输入提示词后联网寻找武汉及周边候选地点，并逐批补充路线。可见卡片自动搜索代表性照片，最多两个地点同时查询，结果缓存30分钟；浏览相册复用同一结果。图片来源包括高德地图、附近1.5公里内的Wikimedia Commons，以及智谱联网搜索返回的公开摄影、游记、文旅网页（美篇、POCO、携程、马蜂窝、搜狐及武汉/湖北文旅等允许的来源）。每个地点按“人像写真机位”和“风景全景”分别检索，汇集最多48张候选图，视觉模型筛选并按环境代表性排序。封面优先使用地点来源中展示完整环境的照片，相册提供全部、风景、环境人像分类及原文链接。周边照片明确标注范围，不承诺每个地点都有固定数量的人像；不以其他地点素材补齐，加载失败的照片会移除。模型不推断人物身份，视觉筛选不等于地理核验。

网页搜索遵循智谱公开接口：https://docs.bigmodel.cn/cn/guide/tools/web-search 。公开网页仅读取允许来源、不跟随跳转、有超时和大小限制。需要登录或禁止访问的图片不绕过限制，保留原站参考入口。无授权说明的照片注明版权归原作者；Commons保留作者、许可及原文。所有密钥仅在服务端使用。

相册新增“小红书 · 人像参考”入口，按武汉和当前地点名称搜索人像摄影、写真及拍照机位。手机入口在用户点击时复制关键词并直接请求小红书 App 搜索，提供 App 首页备用入口与可见的复制失败提示。手机网页版搜索会返回“页面不见了”，因此手机端不展示该链接；电脑保留网页版搜索，需登录且可能遇到平台安全限制。App 唤起取决于是否安装小红书和浏览器权限，无法由本站保证；尚未自动获取或在本站展示小红书笔记照片。高德与 Wikimedia Commons 的风景相册继续使用独立的风景筛选规则。

运行时环境变量：

- `ZHIPU_API_KEY`：智谱 GLM-4.6V API 密钥
- `AMAP_API_KEY`：高德地图 Web 服务 API 密钥
- `ZHIPU_MODEL`：可选，默认 `glm-4.6v`

npm run build
