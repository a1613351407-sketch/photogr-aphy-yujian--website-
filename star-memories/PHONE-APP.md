# 星迹手机 App

分享 https://xingji-memory-atlas.a1613351407.chatgpt.site/ 即可使用；玉鉴入口 https://yujian-stars.netlify.app/ 发布同一份界面与功能。

这是可安装到手机主屏幕的 PWA，不需要账号。iPhone 用 Safari 打开，分享 → 添加到主屏幕，保持「作为网页 App 打开」开启；安卓用 Chrome 打开，菜单 → 安装应用/添加到主屏幕。也可以直接在浏览器使用。

## 保存和离线

照片、日期、文字写入当前网址的 IndexedDB，保存与编辑不会请求服务器。首次联网打开后，在「安装与备份」确认「离线资源已准备好」，之后可断网打开、查看、创建和编辑回忆。离线缓存只存应用外壳和编译资源，不缓存旧版私人 API。

请固定使用同一网址、浏览器和设备。不同网址和浏览器的本地记录各自独立。清除网站数据、丢失设备或无痕模式会导致未备份数据丢失；浏览器长期保留授权也不能替代备份。

## 备份和旧记录

「安装与备份」可导出包含照片和文字的 JSON 文件，在另一台设备导入合并。已有 ID 跳过，不覆盖原记录；星芒位置冲突时分配空位。导入能否完成取决于设备可用存储与内存；导入失败时原有数据保持不变，请保留备份文件和原设备。照片在保存前压缩，单张最多 4 MB，每段回忆最多 6 张。

「找回当前浏览器的旧版回忆」仅在主动点击时下载旧服务器记录及照片到本机，原服务器数据保留。未点击不发起旧数据请求，新回忆不上传。

## 开发与验证

- `npm run test:local`：IndexedDB 创建、照片字节、编辑、独立设备、备份、冲突、配额失败和事务回滚；验证无联网。Service Worker 检查完整预缓存、离线打开、隐私 API 排除和缓存完整性。
- `npx tsc --noEmit --incremental false`
- `npm run build`：Sites Worker 与完整离线资源清单。
- `npm run build:netlify`：玉鉴静态页面与保留的旧账号接口。

每次构建由 `scripts/write-offline-assets.mjs` 生成资源清单和缓存版本。新版本完整下载后才替换旧缓存；部署不会清空 IndexedDB。

本地实际浏览器测试关闭预览服务器后，成功打开应用、显示已存照片、编辑并刷新保存、离线新增记录。另一独立网址由零条导入备份恢复照片和文字。手机尺寸检查不等同于在真实 iPhone/安卓上完成系统安装。
