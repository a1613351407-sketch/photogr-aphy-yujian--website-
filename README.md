# 玉鉴摄影项目

玉鉴摄影项目的完整源码备份，包含四个相互关联的网站：

- `yujian-homepage`：玉鉴首页
- `photographer-site`：摄影调查问卷与摄影师工作台
- `scenery-finder`：景去，武汉景色与路线推荐
- `star-memories`：星迹，回忆星图

线上网站：

- https://yujian-studio.netlify.app/
- https://yujian-questionnaire.netlify.app/
- https://yujian-scenery.netlify.app/
- https://yujian-stars.netlify.app/

每个子项目可独立安装依赖、构建和部署。真实环境变量、摄影师口令、邮件及第三方服务密钥未包含在仓库中；请根据各项目的 `.env.example` 在本地或 Netlify 环境变量中配置。
